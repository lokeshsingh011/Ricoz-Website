### One important rule for Figma Make

For each flow, we'll give it a **controlled prompt**, and we'll tell Figma Make:

> **Do not modify unrelated existing flows, components, design tokens, routing architecture, or page structures unless required by the current flow. Reuse the established Ricoz design system.**

That will help prevent the classic Figma Make problem where we ask it to add one feature and it redesigns half the application.

### So our working sequence starts here:

**FLOW 01 — First Visit / Homepage**

We'll take that one first, make it presentation-grade, then move to **Flow 02**, and so on.

And because the foundation is already built, we're now in the **actual product-flow construction phase**, not another foundation exercise.
