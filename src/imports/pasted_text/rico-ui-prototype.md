Create a premium, minimal, production-quality UI prototype for the Ricoz digital ecosystem.

Ricoz is a modern business ecosystem with a large portfolio of products and professional services. The platform should feel sophisticated, trustworthy, highly structured, and enterprise-ready.

IMPORTANT:
Do not reference or imitate any other company, product, website, design system, or existing platform. The design must be an original Ricoz experience.

## BRAND DIRECTION

Use Ricoz Red as the primary brand color, using the previously established Ricoz brand red consistently throughout the interface.

Color philosophy:

* Ricoz Red: primary brand/action color
* Warm white / soft neutral: primary page background
* Near-black: primary text
* Muted neutral gray: secondary text
* Very light neutral borders
* Avoid excessive use of red
* Red should function as a strong accent and conversion color

The interface should feel premium because of spacing, typography, hierarchy, proportion, and restraint rather than excessive decoration.

## TYPOGRAPHY

Use a premium editorial serif for major display headings and a refined modern sans-serif for navigation, body copy, labels, metadata, buttons, and interface elements.

Recommended pairing:

* Display / major headings: Instrument Serif
* UI / body / navigation: Inter

Typography should have:

* Large confident headlines
* Tight but elegant heading line-height
* Highly readable body text
* Strong hierarchy
* Small uppercase metadata labels where appropriate
* Generous whitespace

Do not use oversized typography everywhere. Maintain a sophisticated editorial rhythm.

## DESIGN LANGUAGE

Create a modern premium visual language with:

* Large whitespace
* Strong grid system
* Thin subtle borders
* Restrained shadows
* Medium-to-large corner radii
* Clean cards
* Editorial layouts
* Large imagery where useful
* Minimal iconography
* Precise alignment
* Subtle hover states
* Smooth but restrained transitions

Avoid:

* Neon gradients
* Glassmorphism
* Excessive rounded cards
* Heavy shadows
* Crowded dashboards
* Generic SaaS styling
* Excessive animations
* Decorative elements without purpose

## RESPONSIVE DESIGN

Design for:

* Desktop
* Tablet
* Mobile

The desktop experience should use a sophisticated wide-grid layout.

Mobile layouts must be intentionally designed rather than simply shrinking desktop components.
