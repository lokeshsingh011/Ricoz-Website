Yes. For Delhi, I would lock the **visual system before continuing implementation**, so the page doesn't drift back toward the Mumbai/Nagpur language.

## Delhi Visual System

### 1. Core Character

**Strategic · Institutional · Editorial · Authoritative**

The Delhi page should feel like:

> **A strategic advisory environment with technology and execution capability behind it.**

Not a government website, not a corporate brochure, and not a generic consulting template.

---

### 2. Colour System

Keep Ricoz Red as the brand anchor, but use it **more sparingly** than the other franchise pages.

| Role     | Colour    | Usage                           |
| -------- | --------- | ------------------------------- |
| Primary  | `#C41230` | CTA, active states, key accents |
| Ink      | `#141414` | Headlines, primary text         |
| Soft Ink | `#3A3A3A` | Supporting text                 |
| Paper    | `#F7F5F1` | Main background                 |
| White    | `#FFFFFF` | Cards / contrast surfaces       |
| Rule     | `#D9D6D0` | Dividers / borders              |
| Muted    | `#77736D` | Metadata / eyebrow text         |

**Rule:** Red should communicate **importance**, not decorate every section.

---

### 3. Typography

Use the existing Ricoz typography system.

**Display:** Instrument Serif
**UI / Body:** Inter

Delhi should have a slightly more restrained typographic hierarchy.

#### H1

Large, authoritative, approximately:

**64–76px desktop**

Use Instrument Serif selectively for the primary statement.

#### H2

**42–52px**

Strong but controlled.

#### Body

**16–18px**, approximately 1.55–1.7 line-height.

#### Eyebrows

Inter:

* 11–12px
* uppercase
* letter spacing around `0.12em`
* muted colour

#### Metadata

11–13px Inter.

---

### 4. Grid

Delhi should use a **rigorous editorial grid**.

Desktop:

```text
12-column grid
24px gutters
64–80px outer margins
```

Major content should align vertically across sections.

Use visible alignment relationships between:

* hero text
* section headings
* frameworks
* cards
* CTA
* footer

This is what gives the page its institutional quality.

---

### 5. Hero System

The hero is the strongest differentiator.

Use:

**55% content / 45% portrait**

with a hard vertical division.

```text
┌─────────────────────────┬──────────────────────┐
│                         │                      │
│ RICOZ / DELHI           │                      │
│                         │                      │
│ Strategy that moves     │      DIRECTOR        │
│ business forward.       │      PORTRAIT        │
│                         │                      │
│ Supporting copy         │                      │
│                         │                      │
│ CTA                     │                      │
└─────────────────────────┴──────────────────────┘
```

No floating cards.

No rounded image container.

No gradient overlay.

The portrait should feel like a **leadership editorial portrait**.

---

### 6. Borders & Surfaces

Delhi should rely heavily on **rules and alignment**, rather than shadows.

Use:

* `1px` borders
* square or very subtle `4px` radius
* almost no elevation
* flat surfaces
* occasional full-bleed dark section

Avoid:

* glassmorphism
* large shadows
* excessive rounded cards
* floating dashboard aesthetics

---

### 7. Section Rhythm

Use alternating visual densities.

```text
Hero
↓
Large statement
↓
Question framework
↓
Capability system
↓
Product showcase
↓
Service showcase
↓
Solution showcase
↓
Industry matrix
↓
Strategy framework
↓
Leadership
↓
Network
↓
CTA
↓
Footer
```

Not every section should have the same background.

Recommended rhythm:

**Paper → White → Paper → White → Dark → Paper → White → Paper → Dark → Paper**

Use dark sections sparingly.

---

### 8. Cards

Cards should feel like **information modules**, not marketing tiles.

Use:

* thin border
* minimal radius
* generous internal padding
* strong title
* short supporting copy
* small directional arrow

Example:

```text
01

Business Consulting

Strategic clarity for complex
business decisions.

→ Explore
```

No icons unless an icon has actual navigational meaning.

---

### 9. Strategic Framework

This is one of the most important Delhi-specific visual elements.

Use:

```text
01        02        03        04        05

DISCOVER  DEFINE    DESIGN    DELIVER   EVOLVE
```

Each stage should sit on the same horizontal baseline.

Use vertical rules between stages.

On mobile:

```text
01 DISCOVER
│
02 DEFINE
│
03 DESIGN
│
04 DELIVER
│
05 EVOLVE
```

This becomes a signature Delhi component.

---

### 10. Image Treatment

Photography should feel:

**Editorial + leadership-focused + real.**

For the director:

* natural lighting
* professional portrait
* neutral/architectural environment
* confident but approachable expression
* minimal retouching
* no artificial corporate background

For supporting imagery, prefer:

* architecture
* workspaces
* technology
* people collaborating
* business environments

Avoid obvious stock-photo poses.

---

### 11. Motion

Delhi should be the **most restrained** of the franchise pages.

Use:

* 150–250ms transitions
* subtle opacity/translate entrance
* border/underline transitions
* controlled image reveal

Avoid:

* bouncing elements
* dramatic parallax
* excessive stagger
* floating objects
* continuous animation

Motion should reinforce **precision**.

---

### 12. Buttons

Primary:

**Ricoz Red background + white text**

Secondary:

**Transparent / paper background + thin border**

Button height:

**44–48px**

Radius:

**4px**

Use concise labels:

> Discuss your requirement

> Schedule a Consultation

Avoid pill-shaped buttons on Delhi.

---

### 13. Navigation

Franchise identity:

**RICOZ / DELHI**

Keep navigation extremely clean.

The Delhi page should feel more like an executive digital environment than a marketing microsite.

Active states:

**Ricoz Red + subtle underline/indicator**

---

### 14. Footer

Delhi's footer should continue the **structured editorial system**.

Use:

```text
RICOZ / DELHI

────────────────────────────

ECOSYSTEM       COMPANY
Products        About
Services        Leadership
Solutions       Careers
Resources       Contact

────────────────────────────

FRANCHISE NETWORK

Mumbai
Nagpur
Delhi
Kalyan
Kolkata

────────────────────────────

Discuss your requirement →
```

The footer should have strong horizontal rules and clear columns.

|             | Mumbai           | Nagpur       | Delhi              |
| ----------- | ---------------- | ------------ | ------------------ |
| Personality | Executive        | Growth       | Strategic          |
| Composition | Asymmetric       | Open         | Structured         |
| Typography  | Editorial        | Contemporary | Authoritative      |
| Grid        | Flexible         | Open         | Rigorous           |
| Colour      | Premium contrast | Warm/open    | Restrained         |
| Motion      | Moderate         | Light        | Minimal            |
| Cards       | Editorial        | Modular      | Informational      |
| Hero        | 60/40            | Open/central | 55/45 structured   |
| Signature   | Momentum         | Connection   | Strategy framework |

### The governing principle

**Mumbai says:** *Move faster.*

**Nagpur says:** *Grow further.*

**Delhi says:** **Think clearly. Act decisively.**

That should be the visual and emotional foundation for the Delhi implementation.
